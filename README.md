# תשבצון

<div dir="rtl">

משחק תשבצים ללימוד אנגלית: **ההגדרה באנגלית, והתשובה נכתבת בעברית** בתוך לוח תשבץ קלאסי.

- 6 רמות, מ-A1 (מתחילים) עד C2 (מומחה).
- עובד בלי אינטרנט, בלי פרסומות ובלי איסוף מידע.
- אנדרואיד: קובץ APK. אייפון: אפליקציית רשת שמוסיפים למסך הבית (בשלב 3).

## מבנה התיקיות

| תיקייה | מה יש בה |
|---|---|
| `app/` | האפליקציה עצמה (HTML/CSS/JavaScript). זה מה שרץ בטלפון. |
| `app/js/core/` | הלוגיקה של המשחק (לוח, הקלדה, ניקוד, שמירה), בלי תצוגה. |
| `app/js/ui/` | המסכים והרכיבים. |
| `app/data/` | הרמות והתשבצים המוכנים (JSON). |
| `content/vocab/` | מאגר המילים, קובץ לכל רמה. |
| `tools/generator/` | מחולל התשבצים. רץ מראש, לא בטלפון. |
| `android/` | המעטפת של אפליקציית האנדרואיד. |
| `tests/` | בדיקות אוטומטיות. |
| `docs/` | מסמך העיצוב ותוכניות העבודה. |

## פקודות

```bash
npm test                                   # כל הבדיקות
npm run generate -- --level A1 --seed 1    # יצירה מחדש של תשבצי רמה
npm run serve                              # משחק בדפדפן: http://localhost:8080
npm run e2e                                # בדיקה מקצה לקצה + צילומי מסך
```

## התקנה בטלפון אנדרואיד

1. הורד את הקובץ `tashbetzon-0.1.0-debug.apk` לטלפון.
2. פתח אותו מתוך "הורדות" (Downloads).
3. אם מופיעה הודעה על "התקנה ממקורות לא ידועים", אשר אותה עבור האפליקציה שממנה פתחת את הקובץ (למשל Chrome או "הקבצים שלי").
4. לחץ **התקן**, ואחר כך **פתח**.

**חשוב לדעת:**
- זו גרסת ניסיון (debug). לפני עדכון לגרסה חדשה ייתכן שתצטרך למחוק את הקודמת, וההתקדמות תימחק. בשלב 2 נוסיף מפתח חתימה קבוע, ואז עדכונים ישמרו את ההתקדמות.
- נדרש אנדרואיד 7.0 ומעלה, עם רכיב "Android System WebView" מעודכן (מתעדכן אוטומטית מחנות Play).
- לאפליקציה **אין הרשאת אינטרנט**. היא לא שולחת שום מידע.

## בניית ה-APK (למפתחים)

```bash
# דרוש Android SDK (platform 35, build-tools 35.0.0) ו-Gradle 8.14
echo "sdk.dir=/opt/android-sdk" > android/local.properties
gradle -p android assembleDebug
# הקובץ: android/app/build/outputs/apk/debug/tashbetzon-0.1.0-debug.apk
```

## מצאת טעות בתרגום?

התרגומים נכתבו בעזרת AI ויכולות להיות בהם טעויות. כתוב ל-Claude את המילה באנגלית ואת התיקון, והוא יתקן את `content/vocab/` ויצור מחדש את התשבצים.
